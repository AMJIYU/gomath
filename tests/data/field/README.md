# Adaptive field references

`adaptive_scipy.json` is generated by `tests/reference/field_adaptive_scipy.py`.
NumPy 2.3.5 / SciPy 1.17.1 supply independent RK45 sample times and high-accuracy
DOP853 values for six real planar systems, including stiff and backward cases.
The Go tests do not choose these reference times using their own integrator.
No implementation source is copied; development-tool BSD licenses remain with
the installed tools. Ordinary tests require only the checked-in JSON.

The centralized external-package TestMain changes cwd here so fuzz failure
corpora stay under tests/data/field/testdata/fuzz rather than production field/.
