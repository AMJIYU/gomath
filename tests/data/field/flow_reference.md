# Streamline Flow references

`flow_reference.json` is generated by `tests/reference/field_flow_reference.py`.
The polynomial/window oracle uses exact Python fractions and Bernstein basis;
source times/controls are binary-exact. Sample display times include exact decimal
fractions, then JSON binary64 conversion; Go comparisons allow 3e-14 coordinate
rounding. There are 8 configurations × 9 absolute times and 200 point checks.

The Manim section records AST-extracted source updater and flash-bound execution
with minimal stubs, a zero random phase and pinned revision/source hashes. These
are independent clock/bounds observations, not pixel observations. Only the
explicitly converted homogeneous-duration subset is asserted equal; otherwise
physical-second Flow timing deliberately differs. No reference source is edited.
The extracted source is MIT licensed, retained in
`tests/reference/field_flow_MANIM_LICENSE.txt`.

Ordinary Go tests read JSON; they never run Python, Manim or another subprocess.
The separate pixel test compares sampled flow against manually authored expected
window geometry through the pure-Go rasterizer, including an interior frame.
