# Graph mutation reference provenance

`mutation_manim.json` is generated by invoking the actual pinned Graph/DiGraph
implementation through `tests/reference/network_mutation_reference.py`.
Reference commit: `16ea443e2a5f1d79db0a721161411ce916d6e733`; the JSON records the
SHA-256 of `manim/mobject/graph.py` and installed reference module versions.
The read-only checkout is selected explicitly on Python's import path, with
bytecode writes disabled. No generator or Python dependency runs in the product.

Both cases execute initial construction, adding two explicitly positioned dots,
adding three edges, removing one edge and removing two vertices with incident
edges. The JSON captures ordering, positions, selected axis-aligned endpoints,
identity and root/dictionary cleanup. Tests match the valid common subset.
`docs/NETWORK_MUTATIONS.md` lists differences in root layering, arrow tips,
automatic endpoint creation, atomic errors and animation/updater policies.
There is no claim of full Manim mutation/pixel parity. No Manim implementation
source is copied into the Go runtime; the script calls its public APIs.
