# Pinned intermediate-animation reference

`manim-animation-0.22.1.json` was generated by Manim Community 0.22.1,
commit `16ea443e2a5f1d79db0a721161411ce916d6e733`, using the complete
development-only generator in `tests/reference/animation.py`. The fixture records
its generator SHA-256. Go tests consume the checked-in JSON and never run Python.

The 35 cases use seven samples (including five interior samples) for each of:

- linear translation of the exact same 16 cubic control points;
- a full-turn rotation of those points around the bounding center;
- equal-topology root ReplacementTransform geometry and endpoint scene identity;
- a linear scalar ValueTracker transformation;
- linear MovingCamera frame pan and width interpolation.

The Go comparison uses absolute 1e-9 coordinate/scalar tolerance. This is narrow
numerical/identity evidence. It does not verify raster quality, default easing,
unequal contour alignment, arbitrary replacement topology, nested removal,
camera rotation, dt updater ordering, full TeX, or all related Manim methods.
The API inventory therefore remains unverified. Static Cairo raster evidence
is documented separately in `tests/data/render/README.md`.

Reproduce from the GoMath directory with a clean, source-pinned sibling checkout:

```sh
mkdir -p artifacts/reference
uv run --quiet --isolated --no-project --with ../manim python \
  tests/reference/animation.py artifacts/reference/animation-rerun.json
cmp tests/data/root/manim-animation-0.22.1.json artifacts/reference/animation-rerun.json
CGO_ENABLED=0 go run ./tests/cmd/run -pkg=root -run TestPinnedManimIntermediateBehavior
```

The generator refuses a different source commit/version and refuses overwriting
the output. Python, NumPy and Cairo are independent development reference tools,
not GoMath runtime dependencies. The source checkout is read-only; Manim's
temporary media directory is under `/tmp`.

ApplyWave includes Manim's .01 VMobject handle-to-anchor pre-function scaling
and restoration. Comparing a direct nonlinear transform of control points
would test a different behavior. Geometry/scalar interpolation allows finite
rate overshoot; style channels remain bounded. These fixtures do not verify
arbitrary topology, images, source timing below milliseconds, shared-target
Succession, general appearance/cleanup timing, full font/TeX behavior, or pixels.

To regenerate a new file, substitute the generator and fresh output path into
the command above. Keep the source checkout at the pinned commit and compare
provenance as well as case values. SVG reference images and their independent
CairoSVG/Manim provenance are under `tests/data/svg/`; codec development
validation is documented separately under the corresponding package.

# Shared-object succession

`manim-succession-0.22.1.json` is generated by
`tests/reference/succession.py` against the same pinned Manim version/commit.
It records 51 complete line-cubic rectangle states, including intermediate
control points, for repeated shared-object relative translations, MoveTo,
Scale, repeated rotations with delayed centers, unequal durations and nested
linear sequences. Generator SHA256 is checked by ordinary Go tests. Reference
operations use deferred ApplyMethod/Rotating; animation builders that precompute
targets can behave differently. Absolute coordinate tolerance is 1e-10.
No scene cleanup, arbitrary group clocks, nonlinear sequence clocks or entire
Succession API parity is asserted. GoMath performs scene cleanup per step.


`manim-arc-connections-0.22.1.json` pins33 ArcBetweenPoints and16 TangentialArc constructions,343 linear Transform states including interiors. Every cubic control is checked within2e-11 and the generator hash is verified. These samples do not verify arrowhead defaults, arbitrary3D normal defaults, raster or complete API behavior; see docs/ARC_CONNECTIONS.md.
