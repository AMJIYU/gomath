# Native markup references

`nested`, `scope`, `kerning` and `escaped` SVG/PNG pairs are independently
generated by `tests/reference/text_markup.py`. Styled operands are manually
specified; original fontTools glyph/table analysis and CairoSVG rendering do
not consume Go layout output. `reference.json` contains pinned fonts, hashes,
layout evidence and tool versions. Go font notices are in `LICENSE.txt`.

The kerning case reads the frozen font derivatives under `../fallback/`; their
fixture-only kern/hhea modifications are documented there. Other cases read
original embedded Go Regular/Bold/Italic/BoldItalic source font files.

`preview.png` / `preview.svg` are actual Go review artifacts generated with:

```sh
CGO_ENABLED=0 go run ./tests/reference/_text_markup_preview
```

They are not independent correctness oracles. Pure-Go tests load the frozen
independent images and JSON directly; they never invoke fontTools/Cairo/Pango.
